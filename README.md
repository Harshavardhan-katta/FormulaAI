# FormulaAI

Since the early 2000s, scientists have been researching nanopesticides. Testing these nanopesticides traditionally requires cultivating crops infested with pests, which is costly. For example, the cost of preparing a crop with pests can be around 25 lakhs, and developing the pesticide costs about 15 lakhs. If the test results are positive, this investment is justified; however, if the tests fail, both money and time are wasted.

To avoid such losses, we have designed a predictive model that uses mathematically calculated virtual data to forecast:
- How fast the pesticide releases over time  
- The environmental risk associated with the pesticide  
- The effectiveness of the pesticide against pests  

This forms the core of our **🧑‍🔬 Researchers Module**.

---

## 🌾 Farmers Module
Additionally, we offer a Farmers Module that helps farmers select suitable nanopesticides based on inputs such as:
- Crop type  
- Pest problems  
- Soil type  
- Local weather conditions  

Using the same dataset from our researchers, the system suggests the most appropriate nanopesticide for their specific conditions, optimizing pest control and reducing unnecessary costs and risks.
